# ⛏️ PixelForge · 3D 关卡工坊

一个打开就能用的 2.5D 平台跳跃游戏创作工具：**60 秒画出 3D 关卡 → 一键试玩 → 一条链接分享**。

离线可用、零构建，双击 `index.html` 即可运行（或 `python3 -m http.server` 后访问）。

## 产品目标与验收（一天冲刺 + 3D 升级）

| # | 验收标准 | 验证方式 |
|---|---|---|
| 1 | 离线可用、零构建，浏览器直接打开 | 纯 HTML/CSS/JS + 本地 `vendor/three.min.js` |
| 2 | 3D 方块世界：透视镜头、实时光影与阴影、3D 角色与粒子 | `js/render3d.js`（Three.js `InstancedMesh` + 程序化像素贴图） |
| 3 | 编辑 → 试玩切换 < 50ms，稳定 60fps | `tests/verify.js` 测最大关卡初始化耗时与每帧物理耗时 |
| 4 | 跳跃手感：土狼时间、跳跃缓冲、可变跳跃高度 | `tests/verify.js` 手感用例 |
| 5 | 9 种元素：地面、砖块、单向平台、尖刺、金币、弹簧、敌人、起点、终点 | 编辑器调色板 + 3D 射线拾取绘制 |
| 6 | 撤销/重做、平移、缩放、3D 视角旋转、吸取、自动保存 | 3D 编辑器 |
| 7 | 关卡压缩进 URL，完全还原 | 编码往返测试 + 非法数据拒绝 |
| 8 | 示例关卡可通关 | **束搜索机器人**自动通关并回放验证 |

运行验收：`node tests/verify.js`

## 操作

**编辑**：左键绘制 · 右键擦除 · `1-9` 选元素 · `0` 橡皮 · Alt+点击 吸取 · 空格/中键拖动平移 · `Q`/`E`（或 Shift+空格拖动）旋转 3D 视角 · 滚轮缩放 · `F` 适配视图 · ⌘/Ctrl+Z 撤销 · ⌘/Ctrl+Shift+Z 重做
**试玩**：`P` 试玩 · `Shift+P` 从光标处试玩 · ←→/AD 移动 · 空格/↑ 跳跃 · `R` 重来 · `Esc` 返回编辑

## 架构

```
vendor/three.min.js  本地 Three.js r159 UMD（支持 file:// 直接打开）
js/level.js          关卡模型、RLE+base64url 编码、示例关卡
js/engine.js         确定性物理（固定 1/60s 步长，纯逻辑，可在 Node 中运行）
js/render.js         调色板像素画图标生成（零素材）
js/render3d.js       Three.js 3D 渲染器：程序化像素纹理、InstancedMesh、光影、射线拾取
js/editor.js         3D 编辑器：射线拾取、笔刷插值、撤销栈、平移/缩放/旋转视角
js/main.js           模式切换、游戏循环、镜头跟随、3D 粒子、DOM HUD、WebAudio 音效、分享/导入/导出
tests/verify.js      自动化验收（含束搜索通关机器人）
```

引擎是确定性的、状态可克隆，所以机器人能在 Node 里用束搜索求出通关输入序列，再独立回放验证。
