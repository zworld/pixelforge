# ⛏️ PixelForge · 3D 关卡工坊（第一梯队升级版）

一款对标 *Celeste* 手感 + *Super Mario Maker 2* 机关与编辑器体验的 **2.5D 风格化平台跳跃游戏引擎与关卡工坊**。

**60 秒搭出 3D 机关关卡 → AI 一键验关/观战演示 → 幽灵竞速速通 → 一条链接分享给任何人。**

离线可用、零构建、零外部素材依赖，直接托管 GitHub Pages 或双击 `index.html` 即可运行。

---

## 核心特性（对标业界第一梯队）

### 1. *Celeste* + *Super Mario* 级动作手感（[js/engine.js](js/engine.js)）
- **八向空中冲刺（Air Dash）**：按 `Shift / X / J / L` 朝 8 个方向高速冲刺，可直接撞碎砖块或触发 ON/OFF 开关；落地、踩怪、弹弹簧或触碰充能水晶瞬间重置。
- **超级冲刺跳（Wavedash / Hyperdash）**：在地面冲刺中衔接跳跃，获得超远水平爆发速度并返还空中冲刺。
- **蹬墙滑行 & 蹬墙跳（Wall Slide & Wall Jump）**：贴墙慢滑减速，配墙上土狼时间与起跳锁向，轻松攀爬竖井。
- **顶角平滑修正（Corner Correction）**：向上跳跃头蹭墙角 ≤ 5px 时自动平滑滑出，彻底告别“卡头感”。
- **经典手感细节**：土狼时间（0.1s）、跳跃缓冲（0.12s）、可变跳跃高度、顶点滞空减重（Apex Hang Time）、单向平台按 `↓+跳` 下落、原生手柄（Gamepad）支持。

### 2. 17 种高协同玩法机关（[js/level.js](js/level.js)）
- **地形**：地面 `#`、可顶碎/冲刺破砖 `B`、单向平台 `-`、低摩擦冰块 `I`、踩踏震动崩塌的碎裂浮板 `K`、水平往返机械移动平台 `M`。
- **机关**：尖刺 `^`、高弹弹簧 `S`、空中冲刺充能水晶 `C`、全局 ON/OFF 红蓝开关 `T`、红虚实块 `R`、蓝虚实块 `U`。
- **实体**：连吃升调金币 `o`、可连踩升调的巡逻敌人 `E`、零延迟复活存档旗 `F`、起点 `P`、终点 `G`。

### 3. 第一梯队视听表现与打击感 Juice（[js/render3d.js](js/render3d.js) / [js/audio.js](js/audio.js)）
- **4 大风格化 3D 主题（随 URL 分享）**：`🌿 翠绿草原`、`🌃 霓虹赛博`、`❄️ 冰霜雪山`、`🌋 熔岩地堡`，各自配备自定义 GLSL 渐变天空穹顶、主题像素材质、远景生态（青峰/霓虹摩天楼/极光雪山/火山熔岩海）、3D 飘浮环境微粒与专属程序化 BGM 乐谱。
- **ACES 电影色调映射 + 动态光影 + 主角飘动围巾**：4 段式体素围巾与主角动态点光源实时随冲刺就绪/冷却变色，搭配 3D 冲刺残影与 2–4 帧微顿帧（Hitstop）。
- **程序化 WebAudio 音效引擎**：五声音阶递进吃金币、连踩升调、带通白噪声冲刺风声与 4 主题动态合成 BGM。

### 4. 创作者闭环工具链（[js/editor.js](js/editor.js) / [js/main.js](js/main.js)）
- **内置 4 大主题精品演示关卡**：全部经束搜索 AI 自动验关并确定性回放通过。
- **异步 AI 一键验关 & 3D 观战演示**：在浏览器内直接调用束搜索 AI 验证自制关卡可通关性，并可实时观看 AI 3D 自动通关（随时按键手动接管）。
- **上次试玩轨迹（SMM2 调优神器）**：返回编辑视图后自动以 3D 发光轨迹线标出上次试玩跳跃弧线与死亡点。
- **金色幽灵竞速（Ghost Racer）**：刷新最快通关纪录后自动保存录像，下次重玩出现金色半透明幽灵同屏竞速。
- **自由画笔 / 矩形框选填充（`B` 键）** + 3D 射线拾取 + 完整撤销栈 + v2 紧凑 URL 分享（兼容 v1）。

## 操作速查

- **编辑模式**：左键绘制 · 右键擦除 · `B` 切换画笔/矩形框选 · `1-9`/`0` 快捷键 · `Alt+点击` 吸取 · `空格/中键拖动` 平移 · `Q`/`E` 或 `Shift+空格拖动` 旋转 3D 视角 · 滚轮缩放 · `F` 适配 · `⌘/Ctrl+Z` 撤销 · `⌘/Ctrl+Shift+Z` 重做
- **试玩模式**：`P` 试玩 · `Shift+P` 从光标处试玩 · `←→`/`AD` 移动 · `空格`/`↑`/`W`/`Z`/`K` 跳跃（贴墙蹬墙跳，`↓+跳` 下落单向平台） · `Shift`/`X`/`J`/`L` 八向冲刺 · `R` 从头重来 · `Esc` 返回编辑
